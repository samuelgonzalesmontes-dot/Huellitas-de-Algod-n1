# 🐾 Huellitas de Algodón — Spa & Bienestar Digital para Mascotas (PWA)

> *"Suavidad que se siente, cariño que se nota."*

Aplicación Web Progresiva (**PWA**) diseñada para un spa de mascotas **100% libre de jaulas**, enfocada en eliminar la fricción en el agendamiento, brindar transparencia en tiempo real a los dueños (*pet parents*) y potenciar la venta recurrente de productos dermatológicos.

## ✨ Funcionalidades del Prototipo Web
1. **Cotizador Interactivo en Tiempo Real (COP):** Calcula tarifas exactas según tamaño de la mascota, estado del pelaje y paquete de servicio (*Baño Nube de Algodón*, *Ritual Suavidad Total*, *Primeras Huellitas* y *Membresía Club Algodón*).
2. **Reserva Online + Ficha Clínica Digital:** Registro de alergias, vacunas y nivel de nerviosismo con generación automática de comprobante y cálculo de anticipo (30%).
3. **Trackea tu Peludo (Seguimiento en Vivo):** Línea de tiempo interactiva con simulación de etapas de baño, masaje y reporte fotográfico estilo WhatsApp.
4. **Mini-Tienda Dermatológica & Tarjeta de Fidelidad:** Catálogo de productos hipoalergénicos de continuidad en casa con carrito funcional y tarjeta interactiva de *"Nubecitas"*.
5. **Arquitectura PWA Instalable:** Incluye `manifest.json`, `sw.js` (caché offline) e íconos listos para instalar en Android, iOS y escritorio vía GitHub Pages.

## 🚀 Cómo desplegar en GitHub Pages
1. Sube todos los archivos de esta carpeta a un repositorio público en GitHub.
2. Ve a **Settings → Pages**.
3. En **Source**, selecciona `Deploy from a branch`, elige la rama `main` y carpeta `/ (root)`, y guarda.
4. Abre la URL generada (`https://tu-usuario.github.io/huellitas-de-algodon/`) para probar e instalar la PWA.
